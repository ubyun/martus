# 빛이 머무는 자리 · 3D 교회 마을 사진전

어린양이 되어 작은 교회 마을을 걸으며 미디어팀 사진전을 보는 온라인 공간입니다.
마을에는 예배당, 종탑, 기도의 정원, 카페, 연못이 있고, **빛의 갤러리**에는 전시실이 7개 있습니다.
전시실 하나에 사진 20~30장(최대 80장)을 걸 수 있어요.

- 사이트 주소: **https://ubyun.github.io/martus/**
- 함께 고치는 방법: [CONTRIBUTING.md](CONTRIBUTING.md) · 코드 구조: [docs/코드-안내.md](docs/코드-안내.md)
- 사진을 올리면 2~3분 뒤 자동으로 사이트에 반영됩니다.
- 사진이 하나도 없을 때는 샘플 그림 168점이 걸려 있어요. 실제 사진을 올리면 샘플은 모두 사라집니다.

---

## 1. 처음 한 번만 하는 설정

(이 저장소는 이미 설정되어 있어요. 저장소를 Fork 해서 새로 만들 때만 필요합니다.)

1. 이 저장소의 **Settings → Pages** 로 갑니다.
2. **Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. **Actions** 탭에서 "사진전 배포"가 초록색 체크로 끝나면, Pages 화면에 사이트 주소가 나옵니다.

## 2. 사진 올리기 (누구나 참여)

사진은 전시실 번호 폴더에 올립니다.

| 폴더 | 전시실 |
|---|---|
| `photos/1` | 1전시실 · 예배의 자리 |
| `photos/2` | 2전시실 · 찬양하는 사람들 |
| `photos/3` | 3전시실 · 다음세대 |
| `photos/4` | 4전시실 · 함께 떠난 길 |
| `photos/5` | 5전시실 · 섬김의 손 |
| `photos/6` | 6전시실 · 교회의 사계절 |
| `photos/7` | 7전시실 · 미디어팀의 시선 |

1. 저장소에서 원하는 폴더(예: `photos/3`)를 엽니다.
2. 오른쪽 위 **Add file → Upload files** 를 누르고 사진을 끌어다 놓습니다.
3. 아래 **Commit changes** 를 누르면 끝. 2~3분 뒤 사이트에 걸립니다.

- jpg · png · webp 를 올릴 수 있어요. 아이폰 HEIC 사진은 jpg로 바꿔서 올려 주세요.
- 큰 원본을 올려도 됩니다. 사이트에는 긴 변 2200px 사진과 작은 썸네일로 줄여서 올라가요.
- **파일 이름 순서**대로 걸리고, 파일 이름이 작품 제목이 됩니다. 순서를 정하려면 `01_`, `02_` 처럼 앞에 번호를 붙여 주세요.

**다른 사람도 올릴 수 있게 하려면**
- 미디어팀원: **Settings → Collaborators → Add people** 로 초대하면 바로 올릴 수 있어요.
- 그 밖의 성도: 저장소를 **Fork** 해서 사진을 올린 뒤 **Pull request** 를 보내면, 미디어팀이 확인하고 합칩니다.

## 3. 제목 · 작가 · 설명 적기 (선택)

사진과 같은 폴더에 `captions.csv` 를 올리면 작품 정보가 붙습니다. 양식은 `photos/captions-양식.csv` 를 복사해서 쓰세요.

```
파일,제목,작가,촬영 시기,장소,설명,말씀,말씀 출처
01_새벽기도.jpg,새벽 기도 후,김하은,2026년 3월,본당 2층,아무도 없는 본당.,주의 말씀은 내 발에 등이요 내 길에 빛이니이다,시편 119:105
```

- 구글 시트에서 만들고 **파일 → 다운로드 → CSV** 로 받으면 가장 깔끔해요. 엑셀에서 저장한 CSV도 읽을 수 있습니다.
- 빈칸은 비워 두면 됩니다. CSV에 없는 사진은 파일 이름이 제목이 돼요.

## 4. 전시 제목 · 전시실 이름 바꾸기

`config.json` 을 열고 연필(✏️) 버튼으로 고친 뒤 **Commit changes** 를 누르세요.

- `church`: 교회 · 팀 이름
- `title`: 전시 제목 (입구 간판, 갤러리 간판에 쓰여요)
- `sub`: 한 줄 소개
- `sections`: 7개 전시실의 이름(`name`)과 소개(`desc`)

## 5. 함께 걷기 · 대화 켜기 (선택)

GitHub Pages는 그림 파일만 보여 주는 곳이라, 그대로 두면 **각자 혼자 걷는 사진전**이 됩니다.
같은 시간에 들어온 사람들의 양이 보이고 대화하려면, 무료로 시작할 수 있는 실시간 서비스 **Supabase** 를 연결합니다.

1. [supabase.com](https://supabase.com) 에 가입하고 새 프로젝트를 만듭니다.
2. 프로젝트의 **Project Settings → API** 에서 **Project URL** 과 **anon public** 키를 복사합니다.
3. `config.json` 의 `realtime` 에 붙여 넣습니다.

```json
"realtime": {
  "supabaseUrl": "https://abcd1234.supabase.co",
  "supabaseAnonKey": "eyJhbGciOi...",
  "tables": false
}
```

이것만으로 **함께 걷기 · 대화 · 인사 · 종소리**가 켜집니다.

**기도의 벽 · 촛불 · 다녀간 사람 수**도 모두와 나누려면:

4. Supabase **SQL Editor** 에 `supabase.sql` 내용을 붙여 넣고 **Run** 을 누릅니다.
5. `config.json` 에서 `"tables": true` 로 바꿉니다.

주의할 점
- `anon public` 키는 원래 공개되는 키라 저장소에 넣어도 됩니다. **`service_role` 키는 절대 넣지 마세요.**
- 기도의 벽에 올라온 글은 누구나 쓸 수 있고, 지우는 것은 미디어팀이 Supabase **Table Editor** 에서 합니다.
- 무료 플랜에는 동시 접속 수와 메시지 양 제한이 있어요. 큰 행사로 많은 사람이 한꺼번에 들어올 예정이면 Supabase 요금 안내를 먼저 확인해 주세요.

## 6. 꼭 알아 두세요

- **공개 저장소에 올린 사진은 원본까지 누구나 내려받을 수 있습니다.** 얼굴이 나온 사진은 본인 동의를, 아이들 사진은 보호자 동의를 받고 올려 주세요.
- 저장소를 비공개로 두고 Pages만 공개하려면 GitHub 유료 플랜(Pro · Team)이 필요합니다.
- 대화는 저장되지 않고, 자동으로 걸러 주는 기능도 없습니다. 모임 안내 때 대화 예절을 함께 알려 주세요.
- 성경 구절은 개역개정판에서 짧게 인용했습니다.

## 함께 만들기

- 사진과 아이디어는 누구나 보탤 수 있어요. 아이디어 · 고칠 점은 **Issues** 에 남겨 주세요.
- 코드를 고치고 싶다면 저장소에서 **`.`** 키를 눌러 브라우저 편집기를 열거나, Fork 후 Pull request 를 보내 주세요.
- 자세한 방법은 [CONTRIBUTING.md](CONTRIBUTING.md) 에 있습니다.

## 파일 구성

```
index.html                 3D 마을 전체 (three.js)
config.json                전시 제목 · 전시실 이름 · 실시간 설정
photos/1 ~ photos/7        전시실별 사진 (여기에 올리기)
photos/captions-양식.csv   작품 정보 양식
tools/build-photos.mjs     사진을 줄이고 photos.json 을 만드는 도구
.github/workflows/deploy.yml  올릴 때마다 자동 배포
supabase.sql               기도의 벽 · 촛불 테이블 (선택)
CONTRIBUTING.md            함께 고치는 방법
docs/코드-안내.md           index.html 구역별 설명
```

내 컴퓨터에서 미리 보려면 Node.js 를 설치한 뒤:

```
npm install --no-save sharp
npm run build
npm run dev
```

## 조작 방법

- 바닥 클릭 · 탭: 걷기 / 물건을 누르면 다가가서 사용
- 끌기: 둘러보기 · 휠이나 두 손가락: 확대/축소
- W A S D · 방향키: 걷기 (Shift: 빨리) · Q E: 시점 돌리기
- Enter: 가까운 것 사용 · T: 대화창
- 왼쪽 위 **둘러보기**: 마을 지도와 전시실 바로 가기 · **내 양**: 닉네임과 양 모습 바꾸기
