# 2전시실 · 찬양하는 사람들

이 폴더에 **찬양하는 사람들** 전시실에 걸 사진을 올려 주세요.

- GitHub 화면 오른쪽 위 **Add file → Upload files** 를 누르고 사진을 끌어다 놓으면 됩니다.
- jpg, png, webp 사진을 올릴 수 있어요. 아이폰 HEIC 사진은 jpg로 바꿔서 올려 주세요.
- 파일 이름 순서대로 걸리고, 파일 이름이 작품 제목이 돼요. (예: `01_새벽기도.jpg`)
- 제목·작가·설명을 따로 적고 싶으면 이 폴더에 `captions.csv` 를 같이 올려 주세요. 양식은 `photos/captions-양식.csv` 를 참고하세요.
- 올리고 2~3분 뒤 사진전 사이트에 자동으로 반영돼요.
