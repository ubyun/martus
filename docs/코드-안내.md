# 코드 안내

마을 전체가 `index.html` 한 파일에 들어 있습니다. 위쪽은 화면 틀(HTML · CSS), 아래쪽 `<script type="module">` 이 3D 마을입니다.
3D는 [three.js](https://threejs.org) 0.170 을 CDN에서 불러와 씁니다. 빌드 과정 없이 파일을 고치면 바로 반영됩니다.

스크립트는 `/* ===== 이름 ===== */` 주석으로 나뉘어 있어요. 편집기에서 이 이름으로 검색하면 바로 찾아갈 수 있습니다.

## 구역별 역할

| 구역 | 하는 일 · 자주 고치는 값 |
|---|---|
| `별명 · 전시 정보 · 말씀` | 랜덤 별명 단어(`ADJ`, `NOUN`), 소품 색(`COLS`), 기본 전시 정보(`CFG`), 기도할 때 뜨는 말씀(`PRAY`) |
| `샘플 사진 (코드로 그린 그림)` | 사진이 없을 때 쓰는 그림 8장(`SAMPLES`)을 코드로 그립니다 |
| `렌더러 · 장면` / `캔버스 텍스처` / `재질` | 3D 화면 준비, 간판 · 스테인드글라스 같은 그림 텍스처, 색과 재질(`M`) |
| `조명 · 하늘` | 해 · 달 · 하늘색, 별 |
| `도우미` | 상자 · 벽 · 지붕 만드는 함수(`box`, `wallX`, `wallZ`, `gable`), 부딪힘 영역(`rect`, `circ`), 상호작용 등록(`addIt`) |
| `장소` | 마을 크기(`WORLD_R`), 지도에 나오는 장소(`PLACES`), 길(`PATHS`) |
| `땅 · 산` | 땅 높낮이, 먼 산, 길 그리기 |
| `앉을 자리` | 벤치(`bench`)와 앉는 자리 |
| `입구` ~ `연못` | 장소마다 건물과 물건을 짓는 함수 (`buildGate`, `buildPlaza`, `buildChapel`, `buildBell`, `buildGarden`, `buildCafe`, `buildPond`) |
| `빛의 갤러리 (전시실 7개)` | 미술관 건물(`MUS`), 전시실 위치(`HALLS`), 기본 전시실 이름과 색(`DEF_SECTIONS`, `SEC_COLORS`), 액자를 벽에 나눠 거는 `allocSlots`, 가까운 전시실만 사진을 불러오는 `updateHalls` |
| `길 안내 (안내판 · 노면 표시)` | 갈림길 안내판(`GUIDE_BOARDS`), 길 위의 표시(`FLOOR_MARKS`), 입구의 마을 안내도(`MAP_BOARD`). 장소 이름은 `PLACES` 에서 가져오고, 화살표 방향은 적어 둔 지점 쪽으로 자동 계산됩니다 |
| `샘플 사진 변형` | 샘플 168점의 제목 · 설명 · 말씀(`STITLES`, `STEXT`, `SVERSES`) |
| `나무 · 풀` | 나무 개수와 위치, 나무를 심지 않는 곳(`freeSpot`) |
| `어린양` | 양 종류(`BREEDS`), 소품(`ACCS`), 양 모양(`makeSheep`), 움직임(`animLamb`) |
| `효과 (파티클)` | 하트 · 음표 · 불티 같은 작은 효과 |
| `나 · 카메라` | 걷기, 길찾기(`route` — 건물 문을 거쳐 가는 경로), 부딪힘, 앉기 · 기도 · 인사 |
| `행동` | 종 치기, 촛불 밝히기, 커피 내리기 |
| `입력` / `갱신` | 클릭 · 드래그 · 키보드 · 휴대폰 조이스틱(`joy`), 매 프레임 내 위치와 카메라 계산 |
| `이름표` / `함께 있는 사람` | 머리 위 이름표와 말풍선, 다른 방문자 위치 주고받기(`sendP`, `onPeers`) |
| `지금 있는 곳` | 장소 · 전시실에 들어서면 위쪽에 이름을 띄우는 `updateArea` (장소 범위는 `AREAS`) |
| `낮 · 밤` | 낮과 밤의 색과 밝기(`MODES`) |
| `소리` | 오르간 화음(`CH`), 종소리 · 차임 (모두 코드로 합성, 음원 없음) |
| `작품` / `지도` | 작품 크게 보기, 작품 목록, 사진 불러오기(`loadStatic`), 지도 |
| `기도의 벽` / `전시 관리` | 기도 한 줄 남기기, claude.ai 안에서 쓰는 편집 화면 |
| `공유 기능` | 데이터를 어디서 가져올지 정하는 `connect`, Supabase 실시간 연결(`supabaseRoom`) |
| `대화` / `내 양 꾸미기` | 채팅, 닉네임 · 양 모습 고르기 |
| `루프` / `시작` | 매 프레임 그리기, 처음 불러오기 순서(`boot`) |

## 사진과 기록은 어디서 오나요

`connect()` 가 열린 곳에 따라 세 가지 중 하나를 고릅니다.

1. **GitHub Pages** (일반 웹): `config.json` 과 `photos.json` 을 읽습니다. `photos.json` 은 배포할 때 `tools/build-photos.mjs` 가 `photos/1~7` 폴더를 읽어 자동으로 만듭니다. `config.json` 에 Supabase 키가 있으면 함께 걷기 · 대화가 켜집니다.
   - `supabaseRoom` 은 움직임 · 대화 · 인사를 **broadcast** 로 보내고, 별명 · 모습 · 마지막 위치는 몇 초에 한 번만 **presence** 에 올립니다. (무료 플랜은 presence 를 한 사람당 30초에 5번까지만 받아 줍니다.) 보내는 간격은 접속자 수와 `msgBudget` 에 맞춰 자동으로 늘어나고, 받는 쪽은 `updatePeers` 에서 지난 위치들로 걷는 방향을 어림해 부드럽게 움직입니다.
2. **claude.ai 아티팩트**: claude.ai 가 주는 저장소(`works`, `config/main`, `config/sections`, `notes`, `candles`, `visits`)와 실시간 방을 씁니다. 이때만 오른쪽 위에 **전시 관리** 버튼이 생겨요.
3. **사진이 하나도 없을 때**: 샘플 그림 168점을 겁니다.

## 자주 하는 수정

- **장소를 새로 만들었다면** `PLACES` 에 넣은 뒤, 가까운 갈림길 안내판(`GUIDE_BOARDS`)의 `front` · `back` 목록과 길 위 표시(`FLOOR_MARKS`)에 `["장소 id", [향하는 지점 x, z]]` 를 더해 주세요. 화살표 방향은 자동으로 맞춰집니다.

- **전시실 이름 · 소개**: 코드가 아니라 `config.json` 의 `sections` 를 고치세요.
- **양 종류 추가**: `BREEDS` 에 `{name, wool, face}` 를 하나 더 넣으면 꾸미기 화면에도 자동으로 나옵니다. (`light: 1` 은 밝은 얼굴, `horns: 1|2` 는 뿔, `fluff` 는 털 부피)
- **기도할 때 뜨는 말씀**: `PRAY` 배열에 `['말씀', '출처']` 를 추가하세요.
- **새 장소 만들기**: `buildCafe` 를 참고해 `build…` 함수를 만들고, `boot()` 안에서 부르고, `PLACES` 에 지도 항목을 넣으세요. 걸어서 갈 수 있게 하려면 `PATHS` 에 길도 추가합니다.
- **전시실 벽 배치**: `hallRuns` 가 액자를 걸 벽면 목록이고, `allocSlots` 가 사진 수에 맞춰 나눠 겁니다.

## 시험하기

- `npm run build` 후 `npm run dev` 로 내 컴퓨터에서 확인할 수 있어요.
- 주소 끝에 `?debug` 를 붙이면 콘솔에서 `window.__dbg` 를 쓸 수 있습니다. 예: `__dbg.teleport(21, -3, Math.PI)` (갤러리 로비로 이동), `__dbg.scene.userData.night = true; __dbg.applyMode()` (밤으로).
- 고친 뒤에는 휴대폰 크기에서도 한 번 열어 보세요. 브라우저 개발자 도구의 기기 모드를 쓰면 됩니다.
